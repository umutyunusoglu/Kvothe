# Kvothe - An Open Source Chord Recognition Tool

Kvothe is an open source chord recognition tool developed as an hobby project.
During this project I have also aimed to put forward an open source framework for music theoretical computation in rust.







### Use of AI
During the development of Kvothe the one of the main principles was to use human expertise for coding as much as possible.
The only usage of AI coding was for the hosting of the project with Vercel and final refactoring efforts.
